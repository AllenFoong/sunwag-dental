# Sunwag Dental Surgery — Website

Portfolio project: a bilingual (EN / 中文) website redesign for a dental clinic.

- Plain HTML / CSS / vanilla JS — no build step, no dependencies
- Open `index.html` directly in a browser to view

## Pages

| File                               | Page                                |
| ---------------------------------- | ----------------------------------- |
| `index.html`                       | Home                                |
| `services.html` + `service-*.html` | Services and treatment detail pages |
| `about.html`                       | About the clinic                    |
| `faq.html`                         | FAQ                                 |
| `contact.html`                     | Contact & location                  |

Shared: `style.css`, `i18n.js` (language toggle), `nav.js`, `reveal.js` and other small interaction scripts.

> Status: work in progress.
