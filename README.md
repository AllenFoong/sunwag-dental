# Sunwag Dental Surgery — Website

Portfolio project: a bilingual (EN / 中文) website redesign for a dental clinic.

**Live demo: https://allenfoong.github.io/sunwag-dental/**

> Status: work in progress — the live site reflects the current stage.

- Plain HTML / CSS / vanilla JS — no build step, no dependencies
- Open `index.html` directly in a browser to view locally
